# Bug Report Template

```
ID:             AE-<AREA>-NNN
Title:          [Page or endpoint] What is wrong, in one line
Severity:       Critical / Major / Minor / Trivial
Priority:       P1 / P2 / P3
Found by:       Test case ID(s)
Environment:    URL, browser + version or tool, OS, date

Preconditions:  Account state, data needed

Steps to reproduce:
  1.
  2.
  3.

Expected result:
Actual result:
Evidence:       Screenshot, video, response body, console log
Impact:         Who is affected and how
Notes:          Workaround, frequency (always / intermittent), related defects
```

**Writing tips I follow**

- One problem per report. If two things are wrong, raise two reports and link them.
- The title should make sense in a list without opening the report.
- Steps start from a known state (logged out, empty cart) so anyone can repeat them.
- Severity is about impact on the user; priority is about when it should be fixed.
